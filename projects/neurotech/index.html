Neurotech × Hologram

What if you could move a hologram with your muscles or your brain instead of a camera? A university neurotech club plan to drive my Hologram Workshop with EMG, a prosthesis and EEG through one shared input layer.

The idea

The hologram already responds to camera-tracked hands. This project keeps the hologram and changes what the body uses to talk to it:

  1. EMG gesture control: a forearm (or textile sleeve) muscle sensor drives grab, turn and release. The flagship live demo.
  2. Bionic-arm interaction: a prosthesis user's own arm drives the same object, co-designed with limb-different participants.
  3. BCI telekinesis: a brain signal (SSVEP first, motor imagery as a stretch) moves the object or a virtual wheelchair.

The architecture

Every input (camera, EMG, prosthesis motion sensor, EEG, keyboard) becomes the same kind of "intent event" on one shared bus. The hologram only listens to intents, so inputs can be swapped and compared side by side.

A ReplaySource plays recorded public datasets, so anyone can build and test with no hardware. Milestone 0 is a small engine change: making the hologram's motion advance every frame, not only when a camera frame arrives, so non-camera inputs can move it.

Why it's worth building

None of the parts is new on its own. The value is the combination: a browser app anyone can open instead of a $1,000+ lab setup, one input layer instead of closed single-sensor systems, rich 3D feedback on objects people scanned themselves instead of abstract cursors, and a zero-risk rehearsal space where a failure freezes a hologram, never a person.

No medical claims: it supplements clinical tools and never replaces them.

What I've done so far

  • Mapped prior art and public datasets for all three tracks.
  • Designed the intent-event layer and how it plugs into the hologram.
  • Wrote planners with a decision matrix, budget, roadmap and participant/consent rules.

What's next

Milestone 0 in the hologram, then the replay pipeline with public EMG data, then the first live sensor kit.
